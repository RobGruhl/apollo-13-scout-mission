## Print notes

- **Cards**: 350gsm+ stock; files include the ⅛″ bleed — trim to 3.5″ × 2″.
- **QR codes** (poster 1 + invitation card) decode to `https://apollo13.quest/` —
  zbarimg-verified, error correction Q, dark-on-white. **Never invert colors.**
- **Poster 1 says "Score 8+ trophies. Earn the Apollo card."** — matches the app's
  reward threshold (updated 2026-07-05).
- Color: RGB. Most large-format shops accept RGB PNG; ask for no color-profile
  surprises on the deep blacks.
